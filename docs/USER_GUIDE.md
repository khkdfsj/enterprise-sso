# 普通用户使用手册

## 第一次使用

1. 确认设备连接企业内网、校园网或受控 VPN。
2. 直接打开需要使用的业务系统，不必单独进入认证中心。
3. 业务系统会自动跳转到统一登录页。

## 登录方式

### 账号密码

输入 UserID（学号）和密码。当前批量初始化规则为“学号后六位”，库内只保存 Argon2id 哈希。连续失败达到限制后，账号会暂时锁定 15 分钟。

### 企业微信扫码

在统一登录页选择扫码，用已绑定的企业微信账号确认。管理员未配置企业微信参数或人员未绑定企业微信身份时，扫码入口不会显示。

## 免重复登录

一次认证后，在有效会话期内访问其他已授权系统通常不需要再次输入密码。当前策略是最长 8 小时、连续闲置 2 小时失效。每次进入业务系统仍会重新检查账号状态和应用权限；人员停用、应用停用或授权版本变化后，旧会话不能绕过权限检查。

## 常见问题

- **页面打不开**：确认正在校园网、企业内网或受控 VPN，并使用业务系统原入口或 `http://210.47.163.114/enterprise-sso/`。
- **账号被锁定**：等待 15 分钟，或由管理员核实异常登录。
- **已经登录但没有权限**：统一认证确认了身份，但目标应用仍会检查应用准入规则。
- **扫码入口没有出现**：企业微信配置或个人绑定尚未完成，可先使用密码登录。

不要把密码、验证码、客户端密钥或浏览器 Cookie 发给他人。
