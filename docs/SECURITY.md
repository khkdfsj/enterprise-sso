# 安全边界

## 不进入 GitHub 的内容

- `.env` 和生产环境变量；
- 数据库及 WAL/SHM 文件；
- 用户、任职、审计和登录数据；
- OIDC 私钥、CA 私钥、服务器私钥和 SSH 私钥；
- 客户端密钥、企业微信 Secret、密码 pepper、Cookie 密钥；
- 生产备份和日志。

## 认证策略

- 密码使用 Argon2id，并叠加服务器 pepper。
- 五次失败后锁定 15 分钟。
- OIDC 使用 Authorization Code + PKCE。
- 普通应用不签发长期 refresh token。
- Access Token 默认 10 分钟；SSO 闲置 2 小时、绝对 8 小时。
- 已有 SSO 会话仍需重新检查应用和人员授权。

## 网络隔离

- 118 后端和数据库均不作为本系统的公网入口。
- 114 的隧道密钥只允许转发到 `127.0.0.1:3000`。
- 8443 同时受主机防火墙和 Nginx 来源规则限制。
- 本系统不接管原 80/443，不发送 HSTS。

发现凭据意外提交时，不要只删除 Git 文件；应立即轮换实际凭据，并清理或重写仓库历史。
