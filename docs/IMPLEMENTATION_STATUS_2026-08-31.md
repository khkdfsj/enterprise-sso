- 回滚发布使用 118 的数据库备份和上一 release；不得用 Git 命令替代数据库恢复。
- 181 旧系统只读，不因新系统上线删除、停用或重定向。
- 114 只使用 `/enterprise-sso/` 精确 location，不修改其他站点的监听、HTTPS 策略或访问入口。
